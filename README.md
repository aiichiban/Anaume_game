## プロジェクト概要
2人で遊べるオンライン穴埋め単語ゲームです。単語カードの文字をシールで隠して、お互いに単語を当て合います。

## ルール
1. 入室: 合言葉を決めて2人で同じ部屋に入室します。
2. 出題: 割り当てられた単語の文字をシールで隠して問題を作成します。シールは全体で15枚まで使用できます。
3. 解答: 相手が作った穴埋め問題に解答します。
4. 結果: 残したシールの枚数（1枚1点）と、正解数（1問2点）の合計で最終ポイントが決まります。

## 使用技術
- フロントエンド: HTML, CSS, JavaScript
- データベース: Firebase Realtime Database
- ホスティング: GitHub Pages
